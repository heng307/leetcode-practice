# 我的算法练习

已安装项目级 Algo Sensei，并通过 AGENTS.md 配置中文提示教学、代码随想录主题路线和本地进度记录。

在此项目中对 Codex 说：

> 开始刷题，按代码随想录路线，每次只给一级提示，不直接给答案。

以后可以说“继续刷题”“提示”“再提示一点”“复习错题”“换到链表主题”。只有明确说“看完整答案”才展示完整解法。

- `study/roadmap.md`：按上游顺序整理的目录，含理论、题目和总结。链接含题解，建议做完再看。
- `study/progress.md`：由教练随练习更新的进度和复习日期。
- `practice/`：需要时创建，存放你自己填写的解题代码。
- `.agents/skills/algo-sensei/`：原版 skill 及完整模式文件。

主题顺序：数组 → 链表 → 哈希表 → 字符串 → 双指针 → 栈与队列 → 二叉树 → 回溯 → 贪心 → 动态规划 → 单调栈 → 图论。

本地进度和复习规则是本项目增加的配置，不是 Algo Sensei 原生的自动调度功能。复习在你回来练习时检查，不发送后台提醒。无需额外 API Key 或 MCP 服务；代码提交仍使用题目原平台。
